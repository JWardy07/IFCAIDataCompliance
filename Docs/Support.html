IFC AI Data Compliance Support

IFC AI Data Compliance helps reviewers import EIR/DEIR requirement workbooks, review controlled mappings, assess supported IFC STEP models deterministically, and package evidence for handover review.

Supported Platforms

  • iPhone and iPad running iOS/iPadOS 18 or later.
  • Native macOS running macOS 15 or later.

Supported Inputs

  • EIR/DEIR requirement registers in .xlsx workbooks.
  • IFC STEP text models in .ifc format.
  • IFC schema handling is limited to IFC2X3 and IFC4.

Workflow

  • Import a workbook and review sheet, header, and column mapping before committing requirements.
  • Import an IFC model and retain local source fingerprints for provenance.
  • Review requirement-to-IFC mappings before deterministic assessment.
  • Export authoritative JSON, CSV, Markdown, PDF, and reviewer ZIP packages.

Apple AI Reviewer

The optional Apple AI Reviewer uses on-device Apple Foundation Models where available. AI text is advisory and must be explicitly approved before it is included in exports or reviewer packages. Deterministic assessment results remain authoritative.

Troubleshooting

  • If a workbook will not import, confirm it is an unlocked .xlsx file and review the column-mapping warnings.
  • If an IFC model is rejected, confirm it is IFC STEP text and uses a supported IFC2X3 or IFC4 schema.
  • If Apple AI Reviewer is unavailable, check device eligibility, operating system support, Apple Intelligence settings, and purchase status.
  • If package creation fails, try clearing the current imported session and reimporting the user-selected source files.
