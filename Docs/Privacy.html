IFC AI Data Compliance Privacy

IFC AI Data Compliance is designed as a local-first review tool for user-selected requirement workbooks and IFC models.

Local Processing

  • Workbook and IFC contents are processed on the user's device.
  • The app works from files the user selects through the system file picker.
  • The app stores imported session data locally so the user can review mappings, evidence, and exports.

Data Not Collected by the App

  • No analytics SDK is included.
  • No advertising SDK is included.
  • No app-owned server upload is used for deterministic assessment, export, or reviewer packages.
  • No cloud AI provider, API key, or external AI endpoint is used by the Apple AI Reviewer workflow.
  • The app does not sell user data.

Apple AI Reviewer

Where available, Apple AI Reviewer uses Apple Foundation Models on device. Generated text is advisory and is excluded from exports until explicitly approved by the reviewer.

Reviewer Packages

Reviewer packages contain exported report files, manifest metadata, checksums, and optional reviewer-approved AI text. Source workbook and IFC files are excluded from reviewer packages.

Purchases

Apple processes App Store purchases and purchase restoration. The app reads purchase-entitlement state through StoreKit to unlock the optional Apple AI Reviewer feature.

User Control

Users can clear imported session data in the app and can delete exported files or reviewer packages from their chosen save locations.
